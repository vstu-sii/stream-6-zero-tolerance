# Глоссарий команды

Единые определения для PRODUCT / VO и AI ENGINEER. Эти термины используются в документах, интерфейсе и инструкциях агентам.

| Термин | Что означает в проекте |
|---|---|
| Студент | Пользователь, самостоятельно решающий учебные математические задачи |
| Сегмент | Первокурсники технических направлений, застрявшие при подготовке к контрольной |
| Дисциплина | Учебная область, например математический анализ или линейная алгебра |
| Тема | Ограниченная часть дисциплины: производные, пределы, умножение матриц |
| Навык | Конкретное проверяемое действие, например применить правило производной сложной функции |
| Учебная задача | Условие с определённым вопросом и проверенным способом оценить ответ |
| Попытка | Одно представленное студентом решение задачи |
| Шаг решения | Пронумерованное действие в попытке; нумерация начинается с 1 |
| Первый ошибочный шаг | Самое раннее неверное действие; для правильного решения - null |
| Ошибка правила (conceptual) | Пропуск или неверное применение математического правила в наблюдаемом решении |
| Вычислительная ошибка (arithmetic) | Неверное вычисление либо алгебраическое преобразование после правильного выбора метода |
| Отсутствие ошибки (none) | В проверенной последовательности шагов ошибка не обнаружена; это не статус непроверяемого решения |
| Непроверенное решение | Не хватает данных или метода проверки; нельзя приравнивать к none |
| Диагностика | Определение проблемного шага и предполагаемого характера затруднения |
| Пробел в знаниях | Устойчивое затруднение, подтверждаемое несколькими наблюдениями; одна ошибка его не доказывает |
| Подсказка | Конкретное действие или вопрос, помогающий продолжить решение без выдачи готового ответа |
| Похожая задача | Новое упражнение на тот же навык с изменёнными данными |
| Самостоятельное решение | Попытка без подсказки и просмотра ответа в ходе выполнения; в пилоте фиксируется наблюдением |
| Учебный цикл | Исходная попытка, помощь и самостоятельная попытка на новой похожей задаче |
| Успешный перенос | Правильное самостоятельное решение новой задачи после помощи с исходной |
| North Star | Доля завершённых циклов с успешным переносом; точный расчёт задан в PRD |
| Агентная роль | Компонент с отдельной задачей и инструкцией; может использовать ту же модель, что другие роли |
| Оркестрация | Управление порядком проверок и вызовов ролей, включая обработку ошибок |
| Проверяющий компонент | Независимая от текстовой генерации проверка поддерживаемых математических действий |
| SymPy | Библиотека символьных вычислений; инструмент для части проверок, не универсальный педагогический эксперт |
| Эталон / golden dataset | Проверенные случаи с ожидаемыми результатами для оценки системы |
| Ложная диагностика | Сообщение об ошибке в правильном решении |
| RAG | Поиск подходящих материалов и передача их модели; вручную вставленная памятка сама по себе не реализует поиск |
| Токены и стоимость цикла | Единицы учёта API и сумма затрат всех вызовов за цикл, включая повторы |
| Лимит задержки | Время до первой полезной обратной связи, отдельно от времени самостоятельного решения |

Категории conceptual, arithmetic и none соответствуют исходному эксперименту. Не расширяем значение conceptual до диагноза способностей студента. Новые статусы и поля согласуем перед изменением экспериментальных данных.
